## 🧠 Meet Alpie-Core

**[Alpie-Core](https://github.com/169Pi/Alpie-Core)** is our first-generation reasoning model — a 32B-parameter
system, fine-tuned in 4-bit precision, that punches well above its weight:

| Capability | Result |
|---|---|
| 🧮 Math (GSM8K) | **92.75%** |
| 📚 General knowledge (MMLU) | **81.28%** |
| 💻 Coding (SWE-Bench Verified) | **57.8%** |
| 🧩 Context window | **65K tokens** |
| ⚡ Runs on | ~16GB VRAM (vs. full-precision models needing 4x that) |

It's the first 4-bit reasoning model out of India, trained on just 8 GPUs, and it's fully open —
[Apache 2.0 licensed](https://github.com/169Pi/Alpie-Core/blob/main/LICENSE), with weights on
[Hugging Face](https://huggingface.co/169Pi/Alpie-Core).

**Before you join the contest below, go star the repo and poke around — you'll need to know
what it does to represent it.**

## 🎨 Make This README Yours

We're running an ongoing experiment:

> **What's the most creative way to represent what Alpie-Core does?**

Pick a capability — reasoning, math, coding, quantization efficiency, its speed, its size,
anything real about the model — and represent *that*. Could be:
- A math formula or proof
- ASCII art
- A haiku
- A code snippet that computes or visualises it
- A benchmark turned into art
- An analogy, a joke, a diagram
- Something we haven't even thought of yet

We want to see it. **Open a PR and show us.**

## 🔄 How It Works

| Step | What to do |
|------|-----------|
| ⭐ | **Star** [Alpie-Core](https://github.com/169Pi/Alpie-Core) — a bot checks this automatically on your PR |
| 💬 | **Join our [Discord](https://discord.gg/REPLACE_WITH_INVITE)** |
| 1️⃣ | **Fork** this repo |
| 2️⃣ | Add your representation of an Alpie-Core capability anywhere in this README under the [Wall of Fame](#-wall-of-fame) section |
| 3️⃣ | Open a **Pull Request** with the title format: `[169pi] Your Name — Your Medium`, and check off the PR checklist |
| 4️⃣ | Wait for a review from the team |
| 5️⃣ | Get merged → **get swag** 🎁 |

No complex setup. No prerequisites. Just curiosity and creativity.
